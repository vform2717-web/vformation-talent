For web teams

Add talent profiles to any website

Paste one snippet into an HTML block (WordPress, Elementor, Squarespace, Wix, Webflow). It updates on its own whenever a profile changes.

The whole roster

<script src="https://vform2717-web.github.io/vformation-talent/embed.js" async></script>
<vformation-talent roster></vformation-talent>

One person

<script src="https://vform2717-web.github.io/vformation-talent/embed.js" async></script>
<vformation-talent profile="beaver-fleming"></vformation-talent>

Filter by tag

<script src="https://vform2717-web.github.io/vformation-talent/embed.js" async></script>
