# V Formation talent site

Public talent profiles for V Formation Consulting, served by GitHub Pages.

- `index.html`: roster of everyone who is live
- `<slug>/`: each person's booking page, PDF one-sheet and photos
- `api/talent.json`, `api/<slug>.json`: public profile data
- `embed.js` and `embed.html`: drop-in embed for any website

Rebuilt from the talent ID cards by `tools/build_site.py`. Settings are in `site.json`.
